# litpb

[[中文]](./README-zh_cn.md) [ENG]
### Features
A CLI/TUI tool that converts images into blueprint for the [LittleTiles](https://www.curseforge.com/minecraft/mc-mods/littletiles) mod. 

### History
Previously implemented in Python, but abandoned due to slow performance. 
Currently being rewritten in Rust with the assistance of AI.
